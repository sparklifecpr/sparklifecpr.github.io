# SparkLifeCPR Website

Static GitHub Pages edition for https://sparklifecpr.com.

## Publish
Upload the *contents* of this folder to the root of the GitHub repository, then enable GitHub Pages from the `main` branch and `/ (root)` folder.

## Contact and registration
The contact forms open the visitor's email application and send messages to info@sparklifecpr.com. Stripe Payment Links can be added in `js/config.js`.
